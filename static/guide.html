学习指南

实验一 · 跟踪一次注册

  1. 打开大厅和开发者工具的 Network（网络）。填入用户名和至少 8 个字符的练习密码，点击「注册新账号」。
  2. 点开 POST /api/register。Payload 显示表单，Response 显示后端返回的 JSON，成功状态码是 201。
  3. 在编辑器展开项目根目录的 static，打开 lobby.js。找到 fetch()，这行从浏览器发出请求。
  4. 打开 app.py 找到 register()。Flask 根据网址和请求方法调用它。它校验输入，将密码哈希交给 storage.add_player()。
  5. 打开 space_rocks/storage.py 找到 INSERT INTO players。写入后，app.py 用 jsonify() 返回消息。浏览器里的 lobby.js 用 message.textContent 将消息显示到页面。

注册后点击登录。后端验证密码，浏览器接收会话 Cookie。之后读取战绩时，后端通过会话找到当前玩家。

实验二 · 保存一局

登录后点击「开始桌面游戏」。浏览器发送 POST /api/play，后端在本机启动 Pygame。游戏判定胜负时调用 on_result 回调。提前按 Esc 也会记录退出。返回大厅点击「刷新战绩」，浏览器通过 GET /api/results 读取当前玩家最近的记录。

数据库文件是 data/players.sqlite3。账号保存在 players 表，战绩保存在 results 表。每条战绩的 player_id 对应玩家的 id。

重新启动大厅

在游戏项目根目录运行：

.venv/bin/python app.py

首次安装依赖用 .venv/bin/python -m pip install -r requirements.txt。原单机入口是 .venv/bin/python space_rocks。
